<p><b>PepeNG</b> is an Android client built on open-source projects in the v2rayNG ecosystem, with advanced connection settings and support for multiple proxy configurations.</p>

<h3>Features</h3>
<ul>
<li>Advanced TLS settings, including cipher suites and fingerprint options supported by the current implementation.</li>
<li>Aether core integration alongside the project's existing proxy-core support.</li>
<li>Import, organize and manage proxy configurations.</li>
<li>Test server response delay to compare endpoints. Results depend on your network, operator, configuration and server availability.</li>
<li>Flexible routing and connection settings inherited from the underlying open-source components.</li>
</ul>

<p><b>Network note:</b> PepeNG cannot guarantee connectivity on every carrier or network. Always test your own configurations and connection environment.</p>
